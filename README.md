# 05Timer - 오프라인 고가시성 타이머 (High-Visibility Timer)

외부 라이브러리 및 네트워크 연결 없이 웹 브라우저에서 100% 오프라인으로 작동하는 **고가시성 루프 타이머 & 스톱워치** 애플리케이션입니다.

## 🌟 주요 기능

- **화면 좌상단 1/4 크기 자동 띄우기**:
  - `index.html`을 여는 즉시 브라우저 창이 화면 왼쪽 상단(0,0)에 전체 화면의 1/4 크기(가로 50%, 세로 50%)로 배치됩니다.
  - **`타이머실행.bat` 더블 클릭**: 주소창 없이 화면 좌측 상단 1/4 크기의 전용 깔끔한 앱 창으로 즉시 실행됩니다.
- **📌 맨 위 창 고정 (Always-on-Top / Document PiP)**:
  - 우측 상단의 `📌 맨 위 창` 버튼을 누르거나 `P` 키를 누르면 브라우저의 Document Picture-in-Picture 기능을 활용하여 **다른 모든 프로그램 위에 항상 고정된 플로팅 창**으로 전환됩니다.
- **고가시성 대형 시간 텍스트**: 시간 표기가 화면 가로 폭의 약 80%를 차지하도록 반응형으로 동적 조절되어 멀리서도 직관적인 가시성을 제공합니다.
- **두 가지 작동 모드**:
  - **루프 타이머 (Loop Timer)**: 반복 횟수(기본값 1회) 지정 가능. 1회 완료 시 알림음과 시각 반짝임 효과 후 자동으로 다음 루프를 실행합니다.
  - **스톱워치 (Stopwatch)**: 밀리초(.00) 단위 정밀 스톱워치 제공.
- **키보드 단축키 지원**:
  - `→` (오른쪽 화살표): +10초
  - `←` (왼쪽 화살표): -10초
  - `↑` (위쪽 화살표): +1분 (+60초)
  - `↓` (아래쪽 화살표): -1분 (-60초)
  - `Space`: 시작 / 일시정지
  - `F`: 전체 화면 토글 (Fullscreen)
  - `P`: 맨 위 창 고정 (Always-on-Top)
  - `R`: 리셋
- **빠른 Preset 버튼 (타이머 모드)**: `1분`, `3분`, `5분`, `8분`, `10분`, `15분`, `30분` 버튼 클릭 시 즉시 설정.
- **100% 오프라인 작동 & Web Audio API 사운드**: 외부 오디오 파일 없이 Web Audio API 신디사이저로 알림음을 생성하여 완벽하게 오프라인에서 동작합니다.

## 📁 프로젝트 구조

```text
05timer/
├── index.html        # 메인 HTML 마크업
├── style.css         # 다크모드 & 80% 뷰포트 반응형 타이포그래피 스타일
├── app.js            # 타이머/스톱워치 로직, 1/4 창 조절, PiP 맨 위 창, 단축키, Web Audio
├── 타이머실행.bat     # 더블 클릭 시 바로 화면 1/4 좌상단 앱 창으로 실행하는 배치 파일
└── .agents/          # 에이전트 커스텀 규칙 및 스킬 정의
```

## 🚀 사용 방법

1. **방법 A (권장 - 1/4 크기 전용 앱 창)**: [`타이머실행.bat`](file:///c:/Users/user/Desktop/local/05timer/타이머실행.bat) 배치 파일을 더블 클릭합니다.
2. **방법 B**: [`index.html`](file:///c:/Users/user/Desktop/local/05timer/index.html)을 원하는 브라우저에서 직접 실행합니다. (자동으로 1/4 크기 조절이 시도됩니다)
3. **다른 프로그램 위에 상시 고정**: 상단 `📌 맨 위 창` 버튼이나 `P` 키를 누르면 Document PiP 모드로 전환되어 **다른 작업을 하는 동안에도 항상 최상단에 타이머가 고정**됩니다.
