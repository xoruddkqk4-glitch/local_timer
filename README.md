# 05Timer - 오프라인 고가시성 타이머 (High-Visibility Timer)

외부 라이브러리 및 네트워크 연결 없이 웹 브라우저에서 100% 오프라인으로 작동하는 **고가시성 루프 타이머 & 스톱워치** 애플리케이션입니다.

## 🌟 주요 기능

- **`타이머실행.bat` 1-Click 실행**:
  - `타이머실행.bat`을 더블 클릭하면 자동으로 화면의 왼쪽 상단(0,0)에 1/4 크기 전용 앱 창으로 띄워지며, Windows OS 차원에서 **항상 최상단(Always-on-Top)**에 고정됩니다.
- **상시 표시 빠른 Preset 버튼**: `1분`, `3분`, `5분`, `8분`, `10분`, `15분`, `30분` 버튼이 작은 창 크기에서도 항상 표시됩니다.
- **우측 직관적 단축키 안내 패널**: 컨트롤 하단 우측 영역에 주요 단축키 안내 카드가 깔끔하게 배치되어 있습니다.
- **고가시성 대형 시간 텍스트**: 시간 표기가 화면에 맞춰 동적으로 조절되어 멀리서도 직관적인 가시성을 제공합니다.
- **두 가지 작동 모드**:
  - **루프 타이머 (Loop Timer)**: 반복 횟수(기본값 1회) 지정 가능. 1회 완료 시 알림음과 시각 반짝임 효과 후 자동으로 다음 루프를 실행합니다.
  - **스톱워치 (Stopwatch)**: 밀리초(.00) 단위 정밀 스톱워치 제공.
- **키보드 단축키 지원**:
  - `→` (오른쪽 화살표): +10초
  - `←` (왼쪽 화살표): -10초
  - `↑` (위쪽 화살표): +1분 (+60초)
  - `↓` (아래쪽 화살표): -1분 (-60초)
  - `Space`: 시작 / 일시정지
  - `F`: 전체 화면 토글 (Fullscreen)
  - `T`: 맨 위 창 고정 (Always-on-Top)
  - `R`: 리셋

## 📁 프로젝트 구조

```text
05timer/
├── index.html        # 메인 HTML 마크업
├── style.css         # 다크모드 & 반응형 타이포그래피 스타일
├── app.js            # 타이머/스톱워치 로직, 단축키(T/F/Space/R), Web Audio
├── 타이머실행.bat     # 더블 클릭 시 화면 좌상단 1/4 크기 최상단 고정 앱 창 실행 스크립트
├── launch.ps1        # PowerShell Win32 HWND_TOPMOST 최상단 고정 헬퍼
└── .agents/          # 에이전트 커스텀 규칙 및 스킬 정의
```

## 🚀 사용 방법

1. **권장 실행 방법**: [`타이머실행.bat`](file:///c:/Users/user/Desktop/local/05timer/타이머실행.bat) 배치 파일을 더블 클릭하면 화면 좌측 상단 1/4 크기로 주소창 없이 깔끔하게 열리며 최상단에 자동 고정됩니다.
2. **일반 브라우저 실행**: [`index.html`](file:///c:/Users/user/Desktop/local/05timer/index.html)을 연 후 `T` 키를 누르면 맨 위 창으로 고정할 수 있습니다.
