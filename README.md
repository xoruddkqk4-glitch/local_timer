# 05Timer - 오프라인 고가시성 타이머 (High-Visibility Timer)

외부 라이브러리 및 네트워크 연결 없이 웹 브라우저에서 100% 오프라인으로 작동하는 **고가시성 루프 타이머 & 스톱워치** 애플리케이션입니다.

---

## 🌟 주요 기능 및 특징

### 1. `타이머실행.bat` 1-Click 최상단 실행 (폴더 이동 완전 지원)
- **좌상단 1/4 크기 전용 앱 창**: `타이머실행.bat` 더블 클릭 시 주소창 없는 깔끔한 전용 앱 창 형태로 화면 왼쪽 상단(0,0)에 1/4 크기(가로 50%, 세로 50%)로 띄워집니다.
- **Windows OS 및 Document PiP 지원 (단일 창 모드)**: 📌 `맨 위 창 (T)` 버튼 또는 `T` 키 입력 시 브라우저 최상단 고정 팝업(Document Picture-in-Picture) 창으로 즉시 전환됩니다. 전환 시 부모 창을 화면 밖(`-32000, -32000`)으로 자동 은닉하여 화면에는 항상 맨 위에 떠 있는 타이머 창 1개만 표시되며, 복원 시 듀얼 모니터 환경에서도 원래 있던 보조 모니터 좌표로 정확히 복귀합니다.
- **폴더 이동 및 크롬 경로 탐색 강화**: 폴더 위치 변경 시 발생하던 매개변수 오류(MSN 홈 페이지 연결)를 `[System.Uri]` 완전 URI 인코딩으로 해결하였으며, `AppData\Local` 내 사용자 전용 Chrome 경로까지 자동으로 탐색합니다.

### 2. 고가시성 대형 시간 표기
- **동적 자동 폰트 스케일링**: 하단 영역 요소를 1줄로 최소화하고, 시간 숫자(`05:00`) 크기가 화면 폭 및 높이에 맞춰 이탈(Overflow) 없이 가득 차도록 정밀한 감싸기 뷰포트 비율로 동적으로 자동 조절됩니다.

### 3. 두 가지 작동 모드
- **루프 타이머 (Loop Timer)**: 반복 횟수(기본값 1회) 지정 가능. 1회 완료 시 사용자가 선택한 알람음 및 화면 반짝임(Flash) 효과 발생 후 자동으로 다음 루프를 실행합니다.
- **스톱워치 (Stopwatch)**: 밀리초(.00) 단위 정밀 카운트업 제공. 스톱워치 모드 전환 시 상단 `반복 횟수` 조절기가 사라지지 않고 자연스럽게 비활성화(Grayed-out) 처리됩니다.

### 4. 직관적인 상단 메뉴바 & 빠른 설정 (Preset Buttons)
- **빠른 설정 버튼**: `1분`, `2분`, `2분 30초`, `3분`, `5분`, `8분`, `10분`, `15분`, `30분` 지원. 클릭 한 번으로 원하시는 시간을 즉시 설정할 수 있습니다.
- **좌측 정렬 모드 탭**: `루프 타이머`, `스톱워치`, `반복 횟수` 조절기가 상단 좌측에 차례대로 그룹화되어 정렬됩니다.
- **줄바꿈 방지**: 상단 메뉴바의 모든 버튼 텍스트가 창 크기에 상관없이 절대로 두 줄로 잘리지 않고 언제나 깔끔하게 한 줄로 보존됩니다.

### 6. 타이머 알람음 다양화 및 `mp3` 음원 선택 시스템
- **🔔 알람음 설정 팝오버 (단축키: A)**: 상단 알람음 메뉴 버튼 또는 단축키 `A`를 눌러 원하는 알람음과 볼륨을 직관적으로 설정할 수 있습니다:
  1. **야르송 알람 (`mp3/야르송알람.mp3`)**: 경쾌하고 리듬감 있는 멜로디 알림음 (mp3)
  2. **L을 가져가 - 셀카 (`mp3/L을 가져가-셀카.mp3`)**: 보이스 음성 알람 (셀카)
  3. **L을 가져가 - 야채 (`mp3/L을 가져가-야채.mp3`)**: 보이스 음성 알람 (야채)
  4. **L을 가져가 - 크리스크로스 (`mp3/L을 가져가-크리스크로스.mp3`)**: 보이스 음성 알람 (크리스크로스)
  5. **L을 가져가 - 크림치즈허니 (`mp3/L을 가져가-크림치즈허니.mp3`)**: 보이스 음성 알람 (크림치즈허니)
  6. **맑은 차임벨 (`mp3/맑은차임.mp3`)**: 은은하게 울리는 4화음 맑은 벨
  7. **디지털 비프 (`mp3/디지털비프.mp3`)**: 클래식 전자 시계/타이머 스타일의 명확한 펄스 비프음
  8. **우든 마림바 (`mp3/마림바.mp3`)**: 따뜻하고 경쾌한 어쿠스틱 타음
  9. **긴급 사이렌 (`mp3/긴급사이렌.mp3`)**: 작업 집중 환기를 위한 고강도 경보음
  10. **기본 신스음 (Web Audio)**: 외부 파일 없이도 100% 무결 작동하는 오프라인 오실레이터 합성음
- **미리듣기 (▶ / ⏹) & 실시간 볼륨 조절**: 알람음 메뉴에서 각 음원을 즉시 재생/정지하여 테스트할 수 있으며, 0%~100% 볼륨 슬라이더로 원하는 음량을 조절할 수 있습니다.
- **📂 내 MP3 파일 불러오기**: 사용자가 `mp3` 폴더나 PC의 원하는 오디오 파일을 직접 추가하여 알람음으로 등록 및 재생할 수 있습니다.
- **설정 영구 보존 & 안전 폴백**: 선택된 알람음과 볼륨은 `localStorage`에 자동 저장되며, 음원 로드 실패 시 내장 신디사이저 알람으로 안전하게 자동 폴백됩니다.

### 7. 키보드 단축키 지원 (원래 창 & 맨 위 창 모두 완벽 지원)
- `Space`: 시작 / 일시정지 (버튼 포커스 자동 제거로 이중 실행 및 맨 위 창 닫힘 방지)
- `→` (오른쪽 화살표): +10초
- `←` (왼쪽 화살표): -10초
- `↑` (위쪽 화살표): +1분 (+60초)
- `↓` (아래쪽 화살표): -1분 (-60초)
- `R`: 리셋
- `T` (또는 `P`): 맨 위 창 고정 토글 (Always-on-Top / Picture-in-Picture)
- `M`: 디자인 테마 선택 팝오버 열기 / 닫기
- `A`: 타이머 알람음 설정 팝오버 열기 / 닫기
- `Esc`: 디자인 테마 또는 알람음 팝오버 닫기
- `D`: 낮/밤 모드 테마 전환 (Light / Dark Theme)
- `1` ~ `4`: 창 크기 단계적 조절
  - **복원 모드**: `1` (35%), `2` (50%), `3` (65%), `4` (80%)
  - **맨 위 창 모드**: Chromium 보안 최댓값 한도(~50%)에 맞춰 `1` (25%), `2` (33%), `3` (42%), `4` (50% 최댓값) 단계별 스케일링 적용
- `5` (또는 `F`): 맨 위 창 모드에서도 매끄럽게 여백 없이 전환되는 100% Fullscreen 전체 화면

### 8. 100% 오프라인 동작 & Web Audio API
- 외부 네트워크나 CDN 의존성 없이 순수 Web Audio API 신디사이저 및 로컬 `mp3` 음원으로 알림음을 재생하여 완벽하게 오프라인에서 동작합니다.
