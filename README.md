# 05Timer - 오프라인 고가시성 타이머 (High-Visibility Timer)

외부 라이브러리 및 네트워크 연결 없이 웹 브라우저에서 100% 오프라인으로 작동하는 **고가시성 루프 타이머 & 스톱워치** 애플리케이션입니다.

## 🌟 주요 기능

- **`타이머실행.bat` 1-Click 최상단 실행 (폴더 이동 완전 지원)**:
  - `타이머실행.bat`을 더블 클릭하면 폴더가 어느 위치로 이동하더라도(Desktop, Downloads, C:\ 등) 자동으로 경로를 인코딩하여 화면 왼쪽 상단(0,0)에 1/4 크기 전용 앱 창으로 열리며, Windows OS 차원에서 **단 하나의 창이 항상 최상단(Always-on-Top)**에 고정됩니다.
  - 사용자 계정에 설치된 Chrome(`AppData\Local` 및 `Program Files`)을 폭넓게 탐색하여 Chrome 우선 실행을 보장합니다.
- **버튼 텍스트 줄바꿈 방지 (`white-space: nowrap`)**: 상단 메뉴바의 모든 버튼 텍스트(`루프 타이머`, `스톱워치`, `반복 횟수`, `📌 맨 위 창`)가 창 크기가 작아져도 두 줄로 짤리지 않고 깔끔하게 한 줄로 보존됩니다.
- **하단 단축키 안내 한 줄 배치**: 컨트롤 하단 한 줄로 단축키 안내(`Space`, `→←`, `↑↓`, `R`, `T`, `F`)가 깔끔하게 배치됩니다.
- **고가시성 대형 시간 텍스트**: 시간 표기가 화면에 맞춰 동적으로 조절되어 멀리서도 직관적인 가시성을 제공합니다.
- **두 가지 작동 모드**:
  - **루프 타이머 (Loop Timer)**: 반복 횟수(기본값 1회) 지정 가능. 1회 완료 시 알림음과 시각 반짝임 효과 후 자동으로 다음 루프를 실행합니다.
  - **스톱워치 (Stopwatch)**: 밀리초(.00) 단위 정밀 스톱워치 제공.
- **키보드 단축키 지원**:
  - `→` (오른쪽 화살표): +10초
  - `←` (왼쪽 화살표): -10초
  - `↑` (위쪽 화살표): +1분 (+60초)
  - `↓` (아래쪽 화살표): -1분 (-60초)
  - `Space`: 시작 / 일시정지
  - `F`: 전체 화면 토글 (Fullscreen)
  - `T`: 맨 위 창 고정 (Always-on-Top)
  - `R`: 리셋

## 📁 프로젝트 구조

```text
05timer/
├── index.html        # 메인 HTML 마크업
├── style.css         # 다크모드 & 고가시성 극대화 타이포그래피 스타일
├── app.js            # 타이머/스톱워치 로직, 최대 폰트 스케일링, 단축키(T/F/Space/R)
├── 타이머실행.bat     # 더블 클릭 시 화면 좌상단 1/4 크기 최상단 고정 앱 창 실행 스크립트
├── launch.ps1        # PowerShell URI 인코딩 & Win32 HWND_TOPMOST 최상단 고정 헬퍼
└── .agents/          # 에이전트 커스텀 규칙 및 스킬 정의
```

## 🚀 사용 방법

1. **권장 실행 방법**: [`타이머실행.bat`](file:///c:/Users/user/Desktop/local/05timer/타이머실행.bat) 배치 파일을 더블 클릭하면 화면 좌측 상단 1/4 크기로 주소창 없이 깔끔하게 열리며 최상단에 자동 고정됩니다.
2. **일반 브라우저 실행**: [`index.html`](file:///c:/Users/user/Desktop/local/05timer/index.html)을 연 후 `T` 키를 누르면 맨 위 창으로 고정할 수 있습니다.
