# 05Timer - 오프라인 고가시성 타이머 (High-Visibility Timer)

외부 라이브러리 및 네트워크 연결 없이 웹 브라우저에서 100% 오프라인으로 작동하는 **고가시성 루프 타이머 & 스톱워치** 애플리케이션입니다.

## 🌟 주요 기능

- **고가시성 대형 시간 텍스트**: 시간 표기가 화면 가로 폭의 약 80%를 차지하도록 반응형으로 동적 조절되어 멀리서도 직관적인 가시성을 제공합니다.
- **두 가지 작동 모드**:
  - **루프 타이머 (Loop Timer)**: 반복 횟수(기본값 1회) 지정 가능. 1회 완료 시 알림음과 시각 반짝임 효과 후 자동으로 다음 루프를 실행합니다.
  - **스톱워치 (Stopwatch)**: 밀리초(.00) 단위 정밀 스톱워치 제공.
- **키보드 단축키 지원**:
  - `→` (오른쪽 화살표): +10초
  - `←` (왼쪽 화살표): -10초
  - `↑` (위쪽 화살표): +1분 (+60초)
  - `↓` (아래쪽 화살표): -1분 (-60초)
  - `Space`: 시작 / 일시정지
  - `F`: 전체 화면 토글 (Fullscreen)
  - `R`: 리셋
- **빠른Preset 버튼 (타이머 모드)**: `1분`, `3분`, `5분`, `8분`, `10분`, `15분`, `30분` 버튼 클릭 시 즉시 설정.
- **100% 오프라인 작동 & Web Audio API 사운드**: 외부 오디오 파일 없이 Web Audio API 신디사이저로 알림음을 생성하여 완벽하게 오프라인에서 동작합니다.

## 🚀 사용 방법

1. [`index.html`](file:///c:/Users/user/Desktop/local/05timer/index.html) 파일을 웹 브라우저(Chrome, Edge, Whale 등)로 엽니다.
2. 원하는 모드(루프 타이머 또는 스톱워치)를 선택합니다.
3. 빠른 Preset 버튼이나 방향키 단축키를 이용해 시간을 조절한 후 `Space` 키나 **시작** 버튼을 누릅니다.
